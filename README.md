# odin-recipes

Project Description: A simple webpage designed using html elements, that displays simple recipes.

index.html is the homepage of the wediste and it conyains all the links to other recipes listed in a list format. Used anchor, image, text html elements to add the content on the site and also connected different pages using relative links.

images folder contains all the images used in the project. recipes folder contains the html file of individual recipes connected to index.html.

By building this simple project, I learnt about different html elements and how to connect different html files using the anchoe element. Learnt to build the folder structure of the project so that all the files are organised and I can access those files easily.
